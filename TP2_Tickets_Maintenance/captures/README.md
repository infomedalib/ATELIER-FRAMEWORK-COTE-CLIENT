## TP2

Enregistrer ici les captures réelles de l'application principale, avec les noms suivants :

1. `01-creation-formulaire.png` — formulaire de création renseigné (ex. Clavier défectueux, priorité Haute).
2. `02-ticket-dans-liste.png` — ticket nouvellement créé visible dans la liste.
3. `03-modification-statut.png` — formulaire de modification avec statut mis à jour.
4. `04-detail-ticket.png` — page de détail d'un ticket.
5. `05-confirmation-suppression.png` — boîte de confirmation affichée avant suppression.
6. `06-validation-champ-obligatoire.png` — formulaire soumis avec un champ obligatoire vide et le message de validation visible.
7. `07-erreur-reseau-ou-404.png` — serveur JSON arrêté (message réseau) ou URL d'un identifiant inexistant (404).

## Comment prendre les captures

- Démarrer `npm run server` dans un terminal.
- Démarrer `npm run dev` dans un deuxième terminal.
- Ouvrir l'application dans le navigateur.
- Utiliser `Win + Shift + S` sous Windows pour capturer la zone utile.
- Enregistrer les images dans ce dossier avec les noms ci-dessus.

Ne pas utiliser des captures d'exemple : les images doivent montrer l'application exécutée localement.
